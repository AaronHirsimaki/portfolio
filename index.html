About_Me.txt - Notepad

Hi there,

I'm Aaron, a full-stack developer from Espoo. I've been on computers for as long as I can remember, and I've played games for just as long. At some point playing them wasn't enough, so I started making my own.

I enjoy building all kinds of software, frontend and backend alike. Java and Python are my strongest languages, React is my frontend of choice, and Lua is what I use for games. The thing I'm proudest of is the collision system in Cat Mayhem, my top-down roguelike. It makes a flat 2D world look and feel 3D. It took a while to crack, and it was worth every attempt.

I've also done this for real. In a client project at Haaga-Helia, I was one of eight developers building a web app for an actual client. I took the lead on deployment, containerising the app with Docker and running it on Kubernetes. I use AI tools like Claude Code to move faster, but I read everything they write. If I don't understand a line, it doesn't ship.

Outside of code, I've been on the live crew at Assembly since 2021, and I spend more time than I'd like to admit tinkering with my Linux setup.

Right now I'm looking for a Full-Stack Developer role. I'm available right away and happy to work in Finnish or English. If that sounds like a fit, say hi.

Thanks for reading,
Aaron

Game · Featured · In development

Cat Mayhem

A chaotic top-down roguelike where you play as a cat fighting through waves of enemies and bosses. Collect loot, unlock weapons, and discover upgrades to survive increasingly intense encounters. Inspired by games like Megabonk.

  • Custom collision system that makes the flat 2D world look and feel 3D
  • Carry up to four weapons at once, each with its own ammo and reload
  • XP and levels, coins, item slots and a dash on cooldown
  • Quests and NPCs: find the gunrunner and the item dealer, then locate the dungeon entrance
  • Several biomes, with hordes of enemies on screen at once

The source code is private, but I'm happy to demo the full game in an interview.
