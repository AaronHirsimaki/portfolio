About Me

AH

I'm a software developer based in Espoo, Finland, who enjoys building well-designed, meaningful software. I believe in continuous learning and strong fundamentals, and I learn fastest by building things hands-on.

My projects span the whole stack: React and TypeScript frontends, Spring Boot and FastAPI backends, React Native mobile apps and 2D games in LÖVE.

AI-assisted development is a core part of my workflow. I use Claude Code, Claude and ChatGPT to prototype ideas quickly, work through tricky problems and ship faster, while I stay responsible for the design and the code that goes out.

I'm always building and always learning, aiming to become the kind of developer who can take any idea all the way to a real, polished product.
